## 项目介绍
本项目基于开源项目 [qilindrop](https://github.com/linzxcw/qilindrop) ，核心实现了配套油猴脚本（Tampermonkey），用于局域网内设备间的文本、文件快捷互传与剪贴板同步。
衷心感谢 qilindrop 作者 [linzxcw](https://github.com/linzxcw) 提供的核心思路、架构与基础代码。
