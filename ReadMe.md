# 征纳互动人数和在线监控

## 项目简介

征纳互动人数和在线监控是一个浏览器用户脚本，用于实时监控征纳互动平台的等待人数和在线状态。脚本支持语音播报提醒、自定义常用语等功能，帮助用户及时响应征纳互动平台的消息。

### 核心特性

- **实时监控**：自动检测征纳互动平台的等待人数和在线状态
- **语音播报**：支持语音播报提醒，及时通知用户有新的等待
- **常用语管理**：内置常用语功能，支持快速回复常用内容
- **工作时间检测**：支持设置工作时间，仅在指定时间段内进行监控
- **日志记录**：记录监控过程中的重要事件，便于问题排查

## 快速开始

### 1. 安装油猴扩展

在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/) 扩展。

### 2. 安装脚本

1. 访问脚本主页：https://scriptcat.org/zh-CN/script-show-page/3650
2. 点击"安装此脚本"按钮
3. 确认安装

或者手动安装：

1. 打开 [`znhd.user.js`](znhd.user.js:1) 文件
2. 点击油猴扩展图标 → 创建新脚本
3. 复制 `znhd.user.js` 的全部内容并粘贴
4. 保存脚本（Ctrl+S）

### 3. 使用脚本

1. 访问征纳互动平台：https://znhd.hunan.chinatax.gov.cn:8443/
2. 脚本会自动启动监控功能
3. 点击右下角的"征纳互动监控"面板进行设置

## 功能说明

### 监控功能

脚本会定期检查征纳互动平台的以下状态：

- **等待人数**：检测当前等待人数，当有人等待时进行语音播报
- **在线状态**：检测平台是否在线，发现掉线时进行提醒

### 语音播报

- 点击"语音播报状态"按钮可以开启/关闭语音播报
- 语音播报使用浏览器内置的语音合成功能
- 支持自定义语音播报内容

### 常用语功能

1. 点击"常用语"按钮打开常用语面板
2. 脚本会自动加载常用语配置文件
3. 点击常用语按钮，内容会自动添加到编辑器中

### 工作时间设置

默认工作时间：
- 上午：9:00 - 12:00
- 下午：13:30 - 18:00

脚本仅在工作时间内进行监控，其他时间自动暂停。

### 日志功能

- 点击"设置"按钮可以查看监控日志
- 日志记录了监控过程中的重要事件
- 支持不同类型的日志：信息、警告、成功、错误

## 配置说明

### 常用语配置

常用语配置文件采用YAML格式，位于 `public/commonPhrases.yaml`。

配置示例：

```yaml
未办理税务登记: |
  【未办理税务登记】
  ●打开 https://etax.hunan.chinatax.gov.cn:8443/xxbg/view/ztxxbg/qssbswzxblwkyqs ，自行打印清税证明
  ●如果上述方法无法正常打印，这边可以给您出具一个未涉税事项证明，需要您通过法人身份登录征纳互动，并将营业执照和法人身份证发送过来

已办理税务登记: | 
  【已办理税务登记】
  ●请先和您的税管员取得联系，税管员同意之后，进入电子税务局电脑端，搜索清税申报（税务注销办理）即可，详细操作流程：https://mp.weixin.qq.com/s/JqIEoAqo-BqWqSCrQYGuMQ
```

### 脚本配置

脚本内部配置项：

```javascript
const CONFIG = {
    CHECK_INTERVAL: 3000,              // 检查间隔（毫秒）
    MAX_LOG_ENTRIES: 20,               // 最大日志条目数
    WORKING_HOURS: {
        MORNING: { START: 9, END: 12 },
        AFTERNOON: { START: 13.5, END: 18 }
    },
    didaUrl: '提示音文件URL',
    commonPhrasesUrl: '常用语配置文件URL'
};
```

## 常见问题

### 语音播报不工作

1. 检查浏览器是否支持Web Speech API
2. 确认语音播报功能已开启
3. 检查浏览器是否允许音频播放

### 常用语加载失败

1. 检查网络连接是否正常
2. 确认常用语配置文件URL是否正确
3. 查看浏览器控制台错误信息

### 监控不工作

1. 确认当前是否在工作时间内
2. 检查征纳互动平台是否正常访问
3. 查看日志面板了解详细错误信息
