## 补充核实：客户端二维码库选型（用户追问）
- `jsqr@1.4.0/dist/jsQR.js`：**解码/扫描库**，API `jsQR(RGBA像素,宽,高)`→返回文本；不能生成二维码图片。方向与我们相反，不可用。
- `qrcodejs@1.0.0/qrcode.min.js`（davidshimjs）：**真正的生成器（编码器）**，IIFE 暴露全局 `QRCode`，API `new QRCode(el,{text,width,height})`，支持 Canvas 且 `canvas.toDataURL("image/png")` 出 dataUrl。CDN 实测返回有效 JS（非404）。**可用作客户端生码**。
  - 注意：qrcodejs 对含中文码有 UTF-8 坑（我们的内容仅 `https://服务器/u/<hex>` 纯 ASCII，无碍）；长 URL 需留意 `typeNumber` 容量。
  - 若切客户端生码，可删掉中继服务器 `/qr` 端点与 `qrcode` npm 依赖；猫面板显示仍走 `createElement('div',{backgroundImage:url})`，因 React 渲染器白名单不放行 `<img>/<canvas>`。当前仍维持「服务器生成 + 脚本 GM_xhr 拉取」方案（已跑通且服务器必存在）。
