### 2026-10-08 · v26.10.08-v1：画廊弹窗新增「打印」按钮（引入 react-to-print）

用户需求：「在现有查看器的基础上增加一个打印按钮」。此前用户要求「先不要改代码，只查找支持打印图片的库」，确认方案后再落地。

**改动文件**：`src/lib/ui/RecvGalleryModal.tsx`、`package.json` + `package-lock.json`（新依赖）、`scripts/smoke/znhd-smoke.html`、`scripts/smoke/run.js`、`config/common.meta.json`、`CHANGELOG.md`、`ReadMe.md`、`AGENT.md`、`dist/znhd.user.js` + 根跳板 `znhd.user.js`。

#### 一、选型结论（查找阶段的结论，后续不要重复调研）

- 当前图片查看 = **antd v6.6.5 的 `Image` / `Image.PreviewGroup`**（v26.10.06-v13 起替代 Viewer.js），它只有变换类工具栏（缩放/旋转/翻转/1:1/切换/关闭），**不自带打印**；扩展点 `actionsRender`（`toolbarRender` 已废弃）可自定义工具栏。
- **主流灯箱都没有打印插件**：Fancybox v6（插件仅 Hash / Compact Mode / Sidebar）、lightGallery（zoom/autoplay/comment/fullscreen/hash/pager/rotate/share/thumbnail/video/mediumZoom）、Yet Another React Lightbox、Viewer.js、PhotoSwipe —— 逐个核对过官方插件清单。所以「换一个自带打印按钮的查看库」这条路不存在。
- 真正「支持打印图片」的是**打印库**，不是查看库。选定 **react-to-print 3.3.0**（MIT，peer 含 `~19`，与项目 React 19.3 兼容；其 devDeps 就是 React 19.2）。
  - 落选：`print-js` 1.6.0（MIT 但 2021 年后停更，功能上也可行）、`react-images-zoom-print` 1.0.9（peerDeps 只到 React 16，**与 React 19 不兼容**）、`html2canvas`（光栅化失真）、Fancybox / lightGallery（GPLv3 + 商业双授权，本项目 MIT）。
- 体积代价：产物 819,318 → 829,360 字节（**+10,042 B ≈ 9.8 KiB**）。

#### 二、⚠️ 最大的坑：打印内容不能用「隐藏容器」

react-to-print 对内容节点做 `cloneNode(true)` 再塞进隐藏打印 iframe。而 **`cloneNode` 会把内联样式一起克隆** ⇒ 用 `display:none` 或 `left:-99999px` 隐藏的容器，在打印 iframe 里**同样不可见，打印出来是空白**。（用 CSS 类隐藏则可绕过，因为 `ignoreGlobalStyles` 不外抄样式；但那依赖「不许关掉 ignoreGlobalStyles」，太脆。）

**正解：临时构造「游离节点」**（`document.createElement`，不挂进 DOM），通过 hook 的**可选内容工厂**传入：

```ts
doPrint(() => node);   // UseReactToPrintFn = (content?: React.UIEvent | (() => ContentNode)) => void
```

- 游离节点只带我们给的打印样式，克隆后正常渲染；
- 不进渲染树 ⇒ 不会「闪一下大图」；
- 且它出现的前提是 `contentRef` 为空（同时传两者会触发 react-to-print 的告警）。

另一个必备项：**`ignoreGlobalStyles: true`**。它默认会把宿主页面**全部** `<style>`/`<link>` 抄进打印 iframe（税务页那一大坨 CSS 会跟着进去，跨域样式表读 `cssRules` 还会告警）。

#### 三、其余设计取舍

- **打印的是原图**（`previewUrl` 原分辨率 objectURL），不是预览里缩放/旋转后的画面 —— 清晰度最好；「所见即所得」不成立（要那个得上 html2canvas 光栅化）。
- ⚠️ **打印对话框弹出期间不能移除该图**：`onRemove` / `onClear` 会 `revokeObjectURL`，objectURL 一失效打印就是空白。弹窗底部提示已写明；`printImage` 注释里也留了这条。
- `pageStyle: '@page { margin: 10mm }'` 给打印页边距；`documentTitle: () => printTitleRef.current` 用文件名当打印对话框标题（react-to-print 打印期间临时改写 `document.title` 再还原）。
- 按钮次序：每张图下方由「复制 / 下载 / ×」变为「复制 / 下载 / 打印 / ×」。

#### 四、冒烟断言（只改不删，26 → 28 项）

- **`printBtnOk`**：画廊弹窗里必须有文案为「打印」的按钮。
- **`printIframeOk`**：点「打印」后必须真的建出 `id=printWindow` 的打印 iframe。
- ⚠️ **判定手法**：headless 里**没有打印对话框**，且桌面 UA 下该 iframe 打印完**会被立刻移除**（react-to-print 在 `print()` 返回后马上清理）⇒ 不能用「iframe 还在不在」判断。改为在测试页 `head` 里装 **MutationObserver**，在**插入那一刻**记录到 `window.__printIframeSeen`。
- 该 iframe **只在「找到了打印内容节点」时才被挂上**（react-to-print 拿不到内容会直接 `return`）⇒ 它出现 = 「按钮 → printImage → doPrint」整条链路真的接通，不是只验证了按钮存在。
- 点击用**程序化 click**（此时放大预览/更新日志弹窗盖在画廊上，真实鼠标点击会打偏），与既有的「复制」断言同款做法。
- 顺带把两条新断言并进冒烟页的 `ALL-OK` 标题判定 —— 否则失败时会打印出「❌ 冒烟测试未通过（znhd-smoke:ALL-OK）」这种自相矛盾的提示。

### 2026-10-08 · v26.10.08-v2：「打印」入口从缩略图行挪进放大预览的工具栏

用户反馈：「我希望将打印加到放大预览的工具栏里面，而不是当前的位置」。**同一天，只递增 `-vN`，日期部分仍是 `26.10.08`**。

**改动文件**：`src/lib/ui/RecvGalleryModal.tsx`、`package.json` + `package-lock.json`（新增直接依赖 `@ant-design/icons`）、`scripts/smoke/znhd-smoke.html`、`scripts/smoke/run.js`、`config/common.meta.json`、`CHANGELOG.md`、`ReadMe.md`、`AGENT.md`、`dist/znhd.user.js` + 根跳板。

#### 一、实现方式：antd v6 的 `actionsRender` + `cloneElement`

- antd v6 预览的自定义工具栏入口是 **`actionsRender`**（`toolbarRender` 已废弃），可从 `<Image.PreviewGroup preview={{ actionsRender }}>` 传，对整组图生效；回调签名 `(originalNode, info)`，`info` 含 `current / total / image / icons / actions`。
- ⚠️ **最大的坑：返回的节点是塞进 `-footer` 的，而 `-footer` 是 `flex-direction: column`**；工具栏的**胶囊背景与圆角长在 `-actions` 容器上**（`node_modules/antd/es/image/style/index.js:284-324`）。所以直接 `return <>{originalNode}{printBtn}</>` 会渲染成「工具栏**下方**一个没有背景的裸按钮」，视觉明显不对。
- **正解**：`cloneElement(originalNode, {}, [...Children.toArray(originalNode.props.children), printBtn])` —— 把按钮**追加进 `-actions` 容器内部**，成为胶囊里的第 7 个图标；按钮复用 antd 自己的 `ant-image-preview-actions-action` 类（尺寸/悬停/颜色与自带图标完全一致），图标用 `PrinterOutlined`。
- 实测 dump（探针）：`actions` 容器内按钮 `aria-label` 依次为 `["flipY","flipX","rotateLeft","rotateRight","zoomOut","zoomIn","print"]`，且 `printBtnInsideActions: true`、带 svg；缩略图行同时回到 `["复制","下载","×"]`。
- 目标图定位：`info.image.url` 是当前预览图的 src（`@rc-component/image/es/Preview/index.js:147` 里 `image = { url: src, ... }`），故优先按 url 反查 `previewUrl`，退回 `info.current`。
  - ⚠️ `ImgInfo` 的字段是 **`url`**，不是 `src` —— 第一版照直觉写了 `image.src`，`tsc` 直接报 `Property 'src' does not exist on type 'ImgInfo'`。
- 新增直接依赖 **`@ant-design/icons` ^6.3.4**：此前只是 antd 的传递依赖，直接 import 属隐式依赖，已显式声明；只用到 `PrinterOutlined`，从包根导入可 tree-shaking。体积 v1 → v2 **+1,220 B**（829,360 → 830,580）。

#### 二、冒烟断言（保持 28 项，语义升级）

- `printBtnOk` 由「画廊里有文案为『打印』的按钮」改为**「按钮必须长在 `.ant-image-preview-actions` 胶囊容器里面且带 svg 图标」** —— 有人把入口挪回缩略图行，这条会直接变红。
- 点击时机改为**轮询等待**（4800ms 起每 200ms 试一次，最多 5s）：预览是 3600ms 由缩略图点开的，固定时刻点击会与 4200/5200 的其它弹窗产生时序耦合。
- ✅ **做了反向验证**：临时把返回值改成 `return <>{originalNode}{printBtn}</>`（即「裸按钮」写法）→ 重建后 `printBtnOk` 与 `printIframeOk` **双双变红**（`znhd-smoke:PARTIAL`，退出码 1），恢复后 28 项全绿。
