### 改写「密钥设置」笔记 → 新增 `.github/workflows/SSH_KEYS_NOTE.md`
- 用户贴的草稿按 Drone 视角写（密钥B=Drone↔服务器、私钥存 Drone 后台）。已改为 GitHub Actions 真实视角：
  - 密钥A：服务器 root 生成 `id_ed25519`，公钥加 GitHub **Deploy keys**（仅需读权限拉代码）；用于服务器侧 `git fetch` SSH 身份。
  - 密钥B：服务器 root 生成独立 `github-actions-deploy`，公钥追加自己 `authorized_keys`，私钥存 **GitHub 仓库 Secrets**（变量 `KEY`，同组 `SERVER_IP`/`USERNAME`/`PORT`）；用于 `appleboy/ssh-action` 登录服务器部署。
  - 两把独立、绝不共用；私钥无 passphrase。
- 该文件与既有 `DEPLOY_NOTE.md` 互补：DEPLOY_NOTE 讲流程/陷阱，SSH_KEYS_NOTE 专讲两套密钥规划/生成/校验。DEPLOY_NOTE 第一节已正确按 GitHub Actions 写，但原缺「密钥A（服务器↔GitHub Deploy key）」说明，本文件补全。
