### 产物体积构成实测（用户问「用了 Tailwind 怎么还这么大 / 是不是借了 CDN」）
- **没借 CDN**：脚本头 `@require` 只有 js-yaml / qrcodejs / heic2any（运行时按需）。
  Tailwind 是**编译期**产物，CSS 以字符串形式打进包里，由 `GM_addStyle` 注入。
- **产物 425.4KB**（未压缩 source 合计 2391.1KB）。按未压缩 source 占比：
  `react-dom 51.9%` > `src 业务代码 15.5%` > `@radix-ui/* 13.7%` > `@floating-ui 7.0%`
  > `shared/ 4.2%` > `其它 node_modules 3.7%` > `react 1.6%` > **`Tailwind CSS 1.5%`** > `scheduler 0.8%`。
- ⚠️ 上面是 source 占比；CSS 是字符串**不参与 JS 压缩**，按最终产物算它约 **36.3KB ≈ 8.5%**（浏览器实测注入 37201 字符）。
- **结论：体积大头一直是 react-dom（约 52%）**，油猴脚本拿不到宿主的 React，只能整包打进去。
  Tailwind 不是负担，antd 移除反而省了 423KB（847 → 424）。
- 统计方法要点：直接按 `stats.modules` 分组会错 —— webpack 的 ModuleConcatenation 把 84 个模块
  内联进 `./src/index.ts`，会误判「业务代码占 55.9%」。**必须递归展开 `m.modules` 内层再分类**。
- 若将来要减重，最大可动的是 `@floating-ui`（167KB，只被 Tooltip 用）与 Radix；react-dom 基本无解。

### 产物体积历史（用户问「前天没用 antd 时体积很小，为什么现在这么大」）
`git rev-list -- dist/znhd.user.js` + `git cat-file -s` 实测各提交产物大小：

| 日期 | 方案 | 加载方式 | 产物 |
|---|---|---|---|
| 10-06 前 | CAT_UI（arco 封装）+ Viewer.js | **CDN `@require`** | **187 KB** |
| 10-06 `56bf281` 移除 CAT_UI 改 antd | antd | npm 打包（未压缩） | 2495 KB |
| 10-06 开 Terser | antd | npm 打包 | 794 KB |
| 10-08 | antd 峰值 | npm 打包 | 827 KB |
| 10-09 现在 | Tailwind + Radix | npm 打包 | 425 KB |

- **⭐ 体积的分水岭不是「用哪个 UI 库」，而是「UI 库从哪来」**：CDN `@require` 不占产物，
  npm 打包就占产物。187KB 那一版的 `@require` 有 5 个（脚本猫 UI 库 / js-yaml / qrcodejs /
  viewerjs / heic2any），产物里几乎只有业务逻辑。
- 现在 425 vs 当时 187，差的 238KB = 被打进产物的 React + ReactDOM + Radix。
- ⚠️ **React 19 已移除 UMD 构建**（`node_modules/react`、`react-dom` **均无 `umd/` 目录**，
  只有 cjs 与 ESM）。而 `@require` 只能加载挂全局变量的 UMD/IIFE 脚本 ⇒
  **React 19 无法直接用 `@require` 走 CDN**。

### CDN UMD 实测（jsdelivr，探测 React/Radix 能否走 @require）
| 目标 | 结果 |
|---|---|
| `react@19.3.0/umd/react.production.min.js` | **404**（React 19 无 UMD） |
| `react-dom@19.3.0/umd/react-dom.production.min.js` | **404** |
| `react@18.3.1/umd/react.production.min.js` | ✅ 10.7 KB |
| `react-dom@18.3.1/umd/react-dom.production.min.js` | ✅ 131.8 KB |
| `@radix-ui/react-dialog`、`react-tabs` | **只有 ESM / .d.ts，无 UMD** |

⇒ 想回小体积的可行路径：**降 React 19 → 18 + `@require` 走 CDN**，可省约 200KB（425 → 约 225KB）。
但 Radix 无 UMD 仍需打包，且要接受「依赖 CDN + 版本降级」两个代价。属带取舍的架构决策，别贸然做。

### 实测：不开 minimize 压缩的产物体积（用户问「如果我不开 minimize 压缩，脚本大小为多少」）
临时建 `config/webpack.prod.nomin.js`（复制 prod，仅 `optimization.minimize = false`）实测构建后已删除：

|---|---|---|---|

## 接入 shadcn/ui（v26.10.09-v3，进行中）

### 前置事实（必须记住，别再猜）
- **shadcn 没有运行时 npm 包**，是 CLI 把组件源码复制进项目。`@shadcn/ui` 只是 0.0.4 占位包。
- **新版 `cn` 是独立包**（`cn@0.4.0`），不再是 clsx + tailwind-merge。官方 manual 文档写明
  `export { cn } from "cn"`。旧的手写 `shared/ui/cn.ts` **不做类冲突合并**，shadcn 组件必须用前者，
  否则外部 className 覆盖不掉组件内置 variant（纯拼接时两个类都在，谁生效看 CSS 顺序）。
- **新组件 import 统一 `radix-ui` 包**（1.7.0），不是分包的 `@radix-ui/react-*`。
- `style` 字段合法值含 `radix-nova` / `base-nova` / `aria-nova` 等（registry schema 枚举），
  本项目已有 Radix 故用 **`radix-nova`**。CLI 的 `--preset` 只接受 nova/vega/maia/lyra/mira/luma/sera/rhea
  （不带 base 前缀），`radix-nova` 传给 `--preset` 会报 "Invalid preset"。
- ⚠️ **`skills add shadcn/ui` 走 git clone 大仓库，本机 GitHub 代理（`http.proxy=socks5h://10808`
  与环境变量 `http_proxy=1859` 并存）会 502 / schannel 断连** ⇒ 装 skill 别指望自动化，让用户手动装。

### 落地配置（已做）
- `components.json`（新建）：style `radix-nova`、tailwind.css 指向 `shared/ui/tailwind.css`、
  aliases 用 **`#ui`**（`#ui/*`）。
- ⚠️ **alias 必须避开 `@/`**：CLI 检测到根目录有 `src/` 就把 `@/` 硬解析成 `src/`，
  于是 `@/ui` 会落进 `src/ui`（手机页 web/ 拿不到，因为 web 只 include src + ../shared）。
  试过 `--path shared/ui` **无效**（CLI 强制按 alias 解析）。改用 **package imports 形式 `#ui`**
  才正确解析到 `shared/ui/`。
  - 但 web/ 是独立包（有自己的 package.json），根目录 package.json 的 `imports` 对它**不生效**，
    故两端都额外配了显式别名：根 tsconfig `#ui/*`→`shared/ui/*`、web tsconfig `#ui/*`→`../shared/ui/*`、
    webpack `resolve.alias['#ui']=shared`、Vite `resolve.alias['#ui']=shared/ui`。
- ⚠️ **CLI 生成的 import 带 `.tsx` 后缀**（`from "#ui/button.tsx"`）⇒ TS5097。已批量去掉后缀
  （只有 dialog/sheet 两个文件有跨组件 import）。以后每次 add 新组件都要再跑一遍这个清理。
- `shared/ui/utils.ts`（新建）：`export { cn } from 'cn'`，是 shadcn 组件的 utils 落点。

### CSS 适配（关键，别照抄官方）
官方 manual 的 CSS 有**两处会污染宿主税务页**，本项目必须改写：
1. `@import "tailwindcss"` 含 **preflight**（全局 reset）→ 仍只导入 `theme` + `utilities` 两层，
   另加官方要求的 `@import 'shadcn/tailwind.css'` 与 `@import 'tw-animate-css'`（这两个不含 reset）。
2. `@layer base { * {...} body {...} }` 是全局选择器 → 改写为 `:where(.znhd-root) *` 与 `:where(.znhd-root)`；
   主题变量也从 `:root` 挪到 `.znhd-root`（`--background` 等通用名放全局会覆盖宿主同名变量）。
   `.znhd-root` = `shared/ui/zindex.ts` 的 `OVERLAY_ROOT_CLASS`，靠继承传给内部 shadcn 组件。
