## 16:10 图片嗅探组内改按时间排序（v26.10.16-v2）

## 18:40 没拿到时间的嗅探卡片加红圈（v26.10.16-v3）

**用户要求**：图片嗅探窗口里，**没获取到图片时间的图，四周加一层红色阴影**。

**设计要点（判据单一出口）**：`sniffConv.ts` 新增导出 **`timeOfItem(it, ctx)`**，与排序里的 `byTimeDesc` **同为 `conv.time === null`** 判定 ⇒ 标红的恰好是排序里被殿后的那批。渲染层只调它、不自己重算（两套口径分叉就会出「没红圈却排在最后」的矛盾提示）。未归属组图在 `byStem` 里查不到 ⇒ 也返回 null ⇒ 也标红。

**⚠️ 红圈用 `box-shadow`、且铺两层**（`ui/SniffModal.tsx` 的 `NO_TIME_RING` 常量）：
- **不用 `border`/`outline`**：`border` 挤内容盒 ⇒ 有圈/没圈卡片尺寸不同、5 列网格错位；`outline` 可能被 `overflow:hidden` 祖先裁掉。`box-shadow` 画在 padding 里**不占布局位** ⇒ 对 `sniffImgActionsOk` 的 `inside`/`bottomRight` 几何断言零影响。
- **只铺 `<img>` 不够**：antd 的 `.ant-image` 内容盒是 `overflow:hidden`（用来裁圆角内的图）⇒ 外扩阴影被裁成方形硬边。故**卡片容器也铺一层**，卡片 `padding: 6` 就是给这层留的落点；两层半径各对齐各自 `borderRadius`（图 8 / 卡 12）。（`.znhd-img-hover` 是普通 div、无 overflow，不是问题源。）

**新增断言 `sniffNoTimeRingOk`**（两侧都钉）：未归属组三张（range/head/perf）**必须**都带圈，有时间的组（当前会话 a、c + 历史 b）**一个都不许**带 —— 少了后半句，「无脑给所有卡片加圈」的镜像 bug 也能过。

**⚠️ 冒烟踩到的坑（两次假红，都是匹配器写错，不是实现错）**：
1. **判据要读 inline `style.boxShadow`，不用 `getComputedStyle`** —— 后者会把 antd/浏览器自带阴影一并读进来，比字符串必然误判。顺手加了 `ringDebug` 调试面（把每张卡的 inline boxShadow 原样打出来），第一次红就是靠它一眼定位是「匹配器错」而非「样式没写上」。
2. **正则必须同时认 `rgb(` 与 `rgba(`**：样式里实际是 `rgba(255, 77, 79, 0.95)`（**不是**浏览器规范化后的 `rgb(...)`），写成 `rgb\(\s*255,77,79\s*\)` 会恒假红。最终用 `/rgba?\(\s*255,\s*77,\s*79[,\s)]/`，并先用 node 单测了 5 个正反用例才重跑冒烟。
3. **`__sniffGroupFacts` 新增 `cardNamesAll`**（跨组展平的文件名）：断言常要「跨组按名字找卡」，逐组拼再 indexOf 容易漏组。

**反向验证（两轮都实跑，两个方向各 1 条）**：
- **A 轮**（`noTimeOf` 恒 `true` = 无条件加圈）⇒ **只红** `sniffNoTimeRingOk`（`ringNames` 三组全红：`["sniff-conv-a.png | sniff-conv-c.png","sniff-conv-b.png","sniff-range.png | ..."]`），其余全绿 ⇒ 证明「有时间的组不许带圈」这半句有判别力。
- **B 轮**（`noTimeOf` 恒 `false` = 都不加圈）⇒ **只红**同一条（`ringNames` 全是空串）。

**门禁**：typecheck / lint（仅既有 1 warning）/ build / verify 全绿。版本号三写 → `26.10.16-v3`（relay 本批零改动，仍 26.10.15-v2）。文档三处同步（ReadMe / AGENT 踩坑表新增 2 条 / changelogs）。
