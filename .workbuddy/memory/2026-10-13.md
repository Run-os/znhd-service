## v26.10.13-v2：产物注入 `// @ts-nocheck`（修 IDE 误报 TS2451）

用户贴来三条 IDE 诊断：`dist/znhd.user.js` 报 `TS2451 无法重新声明块范围变量「Link」`（61004 / 94144 / 104656 行）。

### 排查结论（**不是**真 bug，也不用改业务代码）
- 全文件**只有一处** `const Link`（61004 行，antd `Typography.Link` 的 forwardRef）；另两处报错位置精确落在 **JSDoc 注释**里的单词 `Link` 上（`*   Link,` 与 `* @import {Link, Parents} from 'mdast'`）⇒ VS Code 的 TS 服务在 3.7MB 单文件产物上**解析定位错位**。
- 佐证：文件无 BOM / 无 CR / 无 U+2028/U+2029；`node --check dist/znhd.user.js` 零报错；与本次尺寸改动无关（产物一直是这个体积，只是这次 present_files 打开了它才在 IDE 里报出来）。

### 修法
`config/webpack.config.base.js` 的 `getBanner` 末尾追加 `// @ts-nocheck`（位置在 `==/UserScript==` 之后、webpack bootstrap 之前 —— **不能放文件第一行**，脚本管理器的元数据块必须在首行）。实测：`tsc --ignoreConfig --allowJs --checkJs dist/znhd.user.js` 加之前报上百条（含 TS2451），**加之后 0 条**。
⚠️ `getBanner` 是模板字符串，注释里**绝不能出现反引号**（老陷阱同款）。

### 门禁
`scripts/smoke/run.js` 在「产物新鲜度门禁」之后新增**产物头部结构校验**（首行必须是 `// ==UserScript==` + 元数据块后必须带 `// @ts-nocheck`），顺手把该处重复的 `fs.readFileSync(BUNDLE)` 合并成一次读取。

## v26.10.13-v4：表情悬停放大预览 + 点表情直接发送

两条需求：① 鼠标悬停表情 **0.5 秒**后放大查看，浮层显示中移到别的表情要**实时切换**；② 点表情**不再进「待发图片」，直接发送**。

### 落地
- `EmojiPackPanel.tsx`：新增放大浮层 `.znhd-emoji-hover`（`HOVER_DELAY=500` / `HOVER_BOX=120` / `HOVER_OFFSET=16` / z-index 1000001），portal 到 `getPreviewHost()`（挂 `documentElement`，避开税务页 body 的 transform）、`pointerEvents:'none'`、带 **`data-emoji-url`**（冒烟判「换没换图」就靠它）。
  - **悬停判定 = 网格上的 `mousemove` 委托**（`closest('.znhd-emoji-item')` + `data-emoji-url`），**刻意不用每格的 `onMouseEnter/onMouseLeave`**：React 把 enter/leave 在同一批 mouseover 里成对合成，且**先 leave 再 enter** ⇒ 移到相邻格子会「先收起再重新等 0.5s」，「实时切换」直接失效。
  - 「预览是否已在屏幕上」用 **ref**（`hoverShown`）判：已显示 → 立即换图；未显示 → 同格继续等、换格重新计时（mousemove 每秒几十次，读 state 会拿到闭包旧值）。
  - 悬停的那张若还没下好，浮层内先显示 loading 并补一次 `loadEmojiBlob`；鼠标移出网格即收起。
- `TransferDeviceChat.tsx`：把原 `confirmSendImage` 里的投递逻辑抽成共用 `runSend(list, afterOk)`；`pickEmojiImage` 重写为 **`sendEmojiNow`** —— 表情 blob → `File` → 直接 `runSend(..., noop)`，**不进 `pendingImages`**（发送中再点会记一条「稍后再点」日志）。语义 = 点一下发一张，连点排队逐张发出；「待发图片」区从此只服务「图片上传」。ChatComposer 的 tooltip 与 EmojiPackPanel 底栏文案同步（「点表情直接发送到手机 · 悬停 0.5 秒放大查看」）。
