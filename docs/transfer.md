# 传输助手（手机 ↔ 电脑互传）

适用场景：手机上有纳税人发来的图片（身份证、资料截图等），快速发到电脑剪贴板，在征纳互动聊天框 Ctrl+V 粘贴；也可以反向把电脑的文本 / 图片 / 文件发给手机。

## 使用流程

1. **部署中继服务器**（前置条件，见下）；
2. 电脑端：传输助手 → 第一栏底部「设置」填写中继地址（如 `https://你的服务器:端口`，末尾不带 `/`）；
3. 点第二栏「**+**」打开配对窗口：展示本机专属上传链接 `https://<中继>/u/<设备ID>` 与二维码（本地生成），可发「测试图片」验证链路；
4. 手机打开链接或扫码 → 进入聊天窗 → 选图 / 拍照 / 选文件发送（图片自动压缩：最大边 1600px、JPEG 0.75；SVG 原样直传；HEIC 自动转 JPEG）；
5. 电脑端自动长轮询取回内容，收到的内容进入对应会话；窗口关着时按设置**自动弹出**；在会话里点图片「复制」→ 征纳互动 Ctrl+V。

## 窗口布局（三栏）

- **第一栏（窄图标导航）**：对话 / 文件两个入口（未读角标在「对话」上），底部设置 / 企业信息（中继地址、设备 ID、在线手机，排障先看这里）。
- **第二栏（会话列表）**：搜索 + 「+」配对入口；条目为头像 + 名称 + 最后一条预览 + 时间 + 未读角标；有消息的按最后消息时间排前。文件分组下点条目 = 只看该会话的文件，顶部「全部文件」回到跨会话汇总。
- **第三栏（聊天区）**：气泡左右分栏（我方品牌绿 / 对方主题灰），按 5 分钟时间分隔条分组；图片气泡点击放大（缩放 / 旋转 / 多图切换 / 打印），右下角悬停出现「复制 / 下载 / 删除」；底部输入区支持表情 / 图片 / 任意文件（单次上限 100MB，文件不压缩），文本 Enter 发送。

## 关键机制

- **按设备归组**：每台电脑首次运行生成稳定设备 ID（UUID）；手机上传时携带手机 ID，内容归到**那台手机自己的会话** —— 多台手机同时在线各归各的。
- **按用户隔离**：设备 ID 不可猜测，A、B 电脑各自链接互不串扰；同一电脑可同时开多台手机。
- **长轮询取件**：`GM_xmlhttpRequest` 长轮询 `/recv/<设备ID>`（绕开征纳互动页面的 CSP 限制），在线手机名单由长轮询捎带推送（秒级上下线）；失败按指数退避重连（2s→60s 封顶）。
- **手机端单连接**：一次 `POST /phone/poll` 同时报活与等新内容，省电省流量；老中继自动退回旧模型。
- **会话持久化**：聊天记录（含图片）存本机 IndexedDB（库 `znhd-transfer`），**只保留最近 7 天**自动清理；IndexedDB 不可用时退回内存态。
- **在线表情包**：8 个合集共 568 张，数据由中继一次性缓存到磁盘（`relay-server/data/emoji`），两端优先同源请求，中继不可用自动回退 CDN；表情不进「全部文件」视图。
- **发送状态与进度**：选完即出「发送中」气泡，上传进度逐事件写回气泡内进度条；失败标明原因。

## 中继服务器部署

```bash
cd relay-server
node server.js        # 零依赖，默认端口 5689（PORT 环境变量可改）
```

- 服务器必须能被**手机公网访问**，仅 localhost 手机连不上；
- **更新后必须重启**才生效（`docker restart znhd` / systemd restart）；`curl http://127.0.0.1:5689/health` 返回的 `version` 与 `relay-server/package.json` 一致即生效；
- 同一设备 ID 多标签页同时开着会各自接收（中继广播）；只想一个页面弹窗就关掉其余跑了脚本的标签页。

## 设置隔离

传输助手的设置（中继地址、自动弹出、清空记录）存独立的 `scriptCat_TransferSettings`，与主设置 `scriptCat_Allvalue` 互不干扰。
