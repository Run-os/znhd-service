# 常用语

## 数据源

脚本**直接读取征纳互动页面右侧栏的「常用话术」**（会话人信息 tab 内），与坐席在页面里维护的话术永远一致 —— 不再依赖远程 YAML / 腾讯文档，无需任何配置。实现见 [`src/lib/phrasesZnhd.ts`](../src/lib/phrasesZnhd.ts)。

## 使用

1. 点标题栏「常用语」图标打开侧边栏，自动加载：
   - 本地有缓存 → 直接用缓存，零请求；
   - 无缓存 → 程序化抓取：合成事件展开右侧栏话术树（逐个点开文件夹图标读取懒加载正文），读完自动切回「会话人信息」tab，全程纯 DOM 操作、不干扰坐席操作。
2. 内容分「**全部话术 / 我的话术**」两个 tab，支持关键字搜索。
3. 每条话术一张卡片（3 行截断，悬停看全文），点击后：
   - 自动复制到剪贴板（`GM_setClipboard` 优先，降级 `navigator.clipboard`）；
   - 播放提示音（`dida.mp3`）；
   - 填入页面 TinyMCE 聊天编辑器（自动处理换行与空输入框）。
4. 标题栏右侧的**刷新图标**可无视缓存强制重抓。

## 缓存

抓取成功后写入 `localStorage`（键 `scriptCat_PhrasesCache`）；此后打开侧边栏零请求直读，仅点刷新才重新抓取。

## 排障

抓取失败时提示会带具体原因（如「等待话术面板超时」）。前提：当前页已**进入会话**（右侧栏存在）；若提示「没有读到任何条目」，多为页面改版动了话术树结构 —— 脚本依赖 `span.t-folder-icon`（展开）、`.t-tree__item--open`（展开态）、`.auxiliary-item`（正文）三个选择器，任一变化需同步修改 `phrasesZnhd.ts`。
