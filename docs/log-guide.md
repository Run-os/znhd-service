# 运行日志 · 使用手册

> 面向坐席：脚本「干了什么」都在这里，排障第一步。
> 技术实现（写入管线、去重、20 条上限）见 [log.md](log.md)。

## 1. 它是干什么的

脚本运行过程中的关键动作——播报了什么、抓到了多少条常用语、传输助手连没连上、哪里失败了——都会记进这个弹窗。**自己排不了障没关系，找帮忙时把这页截图发过去**，一眼定位。

## 2. 打开方式

标题栏「设置」→ 弹窗**标题栏右侧**点「**运行日志**」。

![标题栏入口示意](images/navbar-entry.svg)

## 3. 看懂它

- **终端风暗色面板**，每行三段：时间 · 类型 · 内容；最新一条在最下面；
- 类型用四色区分：

| 颜色 | 类型 | 含义 |
|---|---|---|
| 蓝 | 信息 | 正常的过程记录（如「当前等待人数: 2」） |
| 绿 | 成功 | 动作完成（如「已进入工作时间」「图片已下载」） |
| 黄 | 警告 | 不影响功能但要留意（如「找不到人数元素」「语音队列已满」） |
| 红 | 错误 | 出问题了（如「掉线提示」「下载失败： xxx」） |

- 顶部一排**类型筛选**：点某个颜色只看那一类；点「全部」全显/全隐；
- 右下角「**自动刷新**」开关：开着（默认）新日志实时滚动到底；**往上看历史时先关掉它**，列表会冻结在当前快照，不会被新日志顶走；开关状态会记住；
- 「**清空**」一键清空（页面刷新后日志本来也会清零——日志只在内存里，不落盘）。

## 4. 排障时先找什么

| 想排查 | 在日志里搜 |
|---|---|
| 监控 / 播报 | 「找不到人数元素」「无法解析等待人数」「已离开工作时间」 |
| 常用语 | 「抓取」「等待话术面板超时」「没有读到任何条目」 |
| 飞书快捷短语 | 「快捷回复」「刷新失败」「授权」 |
| 传输助手 | 「传输助手」「长轮询」「中继」 |
| 图片嗅探 | 「图片嗅探」「下载失败」「批量下载完成」 |

只有最近 **20 条**——如果问题刚发生，别拖太久再看。
