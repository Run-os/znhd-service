# 常见问题（FAQ）

> 按功能查更细的说明：[监控](monitor-guide.md) · [常用语](phrases-guide.md) · [飞书快捷短语](quick-reply-guide.md) · [待办](todo-guide.md) · [图片嗅探](sniffer-guide.md) · [传输助手](transfer-guide.md) · [运行日志](log-guide.md)

## 语音播报不工作

1. 控制台执行 `'speechSynthesis' in window` 确认浏览器支持；
2. 确认标题栏的语音开关处于开启状态；
3. 浏览器可能需要首次用户交互后才允许发声 —— 点一下页面任意位置再试。

## 常用语抓取失败

1. 确认当前页**已进入会话**（右侧栏有「会话人信息 / 常用话术」tab），未进会话时右侧栏不存在；
2. 看运行日志（设置 → 运行日志）里的具体失败原因；
3. 点**常用语弹窗右上角**的刷新图标强制重抓；
4. 若提示「没有读到任何条目」，多为文件夹未展开或站点改版 —— 见 [phrases-guide.md](phrases-guide.md#4-更新与常见问题)。

## 监控不工作

1. 确认当前时间在监控时间段内（设置弹窗可查可改）；
2. 确认页面已完全加载；
3. 看运行日志了解详细状态。

## 传输助手连不上 / 收不到

1. **中继地址**：传输助手 → 第一栏底部「设置」填写公网可访问地址（末尾不带 `/`）；「企业信息」里核对地址、本机设备 ID 与在线手机；
2. **中继已部署且可达**：`cd relay-server && node server.js`（默认端口 5689）；手机必须能公网访问该服务器；
3. **中继更新后必须重启**（不热更）：`docker restart znhd` 或对应 systemd / PM2 restart；`curl http://127.0.0.1:5689/health` 的 `version` 与 `relay-server/package.json` 一致即生效；
4. **内容落在「手机」聚合会话**：说明中继或手机页版本过旧、识别不到发送者 —— 升级中继并刷新手机页；
5. **多标签页重复弹窗**：中继按广播推送，关掉其余跑了脚本的标签页即可。

更多用法见 [transfer-guide.md](transfer-guide.md)，机制细节见 [transfer.md](transfer.md)。

## 常用语点击后未填入编辑器

1. 确认页面存在 TinyMCE 编辑器（输入区），且页面已进入会话；
2. 脚本**只走 TinyMCE JS API，没有 DOM 兜底**（v26.10.22-v5 起，旧 iframe 兜底已删）——编辑器实例拿不到时会直接失败；
3. 失败不会静默：运行日志里会出现红色「找不到 TinyMCE 编辑器（页面未就绪？）」，看到它刷新页面重试；若日志说「已追加文本并同步」但发送按钮仍是灰的，说明没能同步到输入框组件，同样刷新页面。

> v26.10.25-v1 起「更新日志」弹窗已删除，要看更新记录请到仓库 [`changelogs/`](../changelogs) 目录。
