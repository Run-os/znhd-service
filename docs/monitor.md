# 监控与语音播报

## 工作原理

- **等待人数检测**：每 3 秒读取页面等待人数元素（`.count:nth-child(2)`）；人数 > 0 时语音播报「征纳互动有人来了」。
- **掉线检测**：检测掉线弹窗（`.t-dialog__body__icon` 内含「掉线」文本）；发现即播报「征纳互动已掉线」。
- **时间段限定**：仅监控时间段内执行检测，非工作时段自动暂停（默认上午 9:00–12:00、下午 13:30–18:00，可在设置弹窗调整）。

## 语音播报

- 基于浏览器 `SpeechSynthesis` API（`zh-CN`）。
- 内置语音队列：多条播报按顺序播放，避免重叠；队列有长度上限（10 条）与单条超时保护（15 秒）、消息有效期（30 秒），防止卡死与陈旧播报。
- 静音时自动跳过播报（队列不清空）；开启语音时会先播一条静音语音以解除浏览器的 `not-allowed` 限制。

## 入口

- 语音开关在**站点标题栏**注入控件的最左侧（图标 + 自绘开关），所有弹窗、主面板共用同一份开关状态。
- 运行状态与异常详情看日志：**设置 → 运行日志**。

## 相关配置

运行参数在 [`src/lib/constants.ts`](../src/lib/constants.ts) 的 `CONFIG`（检测间隔、队列上限等，只读）；
用户可改项在同文件 `DEFAULTS`（语音开关、监控时间段、CDN 开关等），运行时存于 `localStorage`（键 `scriptCat_Allvalue`），设置弹窗里直接改，无需动代码。
