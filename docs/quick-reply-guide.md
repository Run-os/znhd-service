# 飞书快捷短语 使用手册

> 面向使用者的操作指南：建表、授权、写规则、排障，照着走就行，不需要看代码。
> 技术实现（数据流、缓存、授权细节、代码地图）见 [quick-reply.md](quick-reply.md)。

## 1. 它解决什么问题

坐席每天要回大量重复问题（「非正常户怎么解除」「申报期到几号」）。这些话术平时都躺在飞书文档或多维表格里，用的时候要切窗口、找、复制、回来粘。

这个功能把最后这步压成**一次点击**：对话里出现「解非」，输入区上方就浮出【非正常户解除】按钮，点一下，输入框里就是完整回复，检查一遍直接发送。

```
┌──────────────────────────────────────────────────┐
│ 快捷短语  (非正常户解除) (申报期限) (发票领用)     │  ← 脚本加的一行按钮
├──────────────────────────────────────────────────┤
│ 表情  截图  文件  …                               │  ← 站点原有工具栏
│ ┌──────────────────────────────────────────────┐ │
│ │ 点按钮后，整段内容替换到这里（不是追加）      │ │
│ └──────────────────────────────────────────────┘ │
│                                     [发送]        │
└──────────────────────────────────────────────────┘
```

三个关键点，先说清楚，免得误期待：

- **它不改你的话术，只负责「找出来 + 填进去」**：按钮文字和填充内容全部来自你自己的表格。
- **它是替换，不是追加**：点之前输入框里写了一半的字会被覆盖 —— 长回复别在输入框里打草稿。
- **它不猜**：只按你给的「标签 / 必含关键词 / 剔除关键词」做字面匹配，命中就显示，不命中就一个按钮都不出现（也不占位置）。

## 2. 用之前要满足两个条件

| 条件 | 说明 |
|---|---|
| **一个能授权的飞书账号** | 建议用**企业版 / 团队版**账号。豆包等第三方登录的账号**授权不了**云文档权限（会报 `access_denied`，见第 9 节）。 |
| **一张飞书多维表格** | 你自己的表，或者别人分享给你、你有「可阅读」权限的表。不需要是管理员，也不需要开放平台建应用。 |

> 全程**不用**去飞书开放平台创建应用、不用配密钥、不用买服务器 —— 脚本会自己注册一个只给你本机用的个人应用（这一步在第 5 节里就是第一次「确认」）。

## 3. 第一步：建好规则表

在飞书里新建一张**多维表格**（不是普通文档）。表里**只认下面这 6 个列名，一字不差**（v26.10.26-v2）：

| 列名 | 类型 | 必需 | 作用 |
|---|---|---|---|
| `标题` | 文本 | 建议填 | 按钮上显示的字。留空时自动取「内容」的前 12 个字 |
| `标签` | 多选（推荐）或文本 | **必填** | 命中关键词。对话里出现其中**任意一个**就显示这个按钮 |
| `内容` | 文本 | **必填** | 点按钮后填进输入框的原文，可以多行 |
| `必含关键词` | 多选或文本 | 可选 | 对话里必须**全部**出现才继续往下判断（为空 = 不约束） |
| `剔除关键词` | 多选或文本 | 可选 | 对话里出现其中任意一个 ⇒ 这个按钮**不显示**（一票否决，优先于其它条件） |
| `是否常显` | 复选框 | 可选 | 勾上 = **无视标签/必含/剔除，永远显示**，排在按钮栏最前方（和普通命中之间有一条竖线隔开） |

> ⚠️ **不做旧列名兼容**：`排除词`、`名称`、`文本`、`信息项`、`项目`、`事项`、`条目`、`字段`、
> `标题（必填）`、`内容/话术` 这类写法**一律不认**，读到就当这张表没有那一列。
> 没有 `标题` 列时按钮显示「内容前 12 个字」，运行日志里会有一条黄色提示让你补「标题」列。

`标签` / `必含关键词` / `剔除关键词` 用多选列最省事；用文本列也行，多个词之间用 `,` `，` `、` `;` 或换行分隔即可。
`是否常显` 建议用复选框列；用文本列的话，填 `true` / `是` / `1` / `√` 都算勾上。
多个词的命中方式不同：`标签` 是**任意一个**命中即过，`必含关键词` 要**全部**命中才过，`剔除关键词` 是**任意一个**命中就整条不显示。

### 表长什么样（照这个填三行就能跑起来）

| 标题 | 标签 | 必含关键词 | 剔除关键词 | 内容 |
|---|---|---|---|---|
| 非正常户解除 | 解非、非正常户、解除非正常 | | 已解除、已经解除 | 您好，非正常户解除需要先到电子税务局提交申请…（此处填你的完整话术） |
| 申报期限 | 申报期、申报到几号、截止日期 | | | 您好，本月的申报期限是…（填你的完整话术） |
| 南岳区办税厅电话 | 电话、联系方式、在哪 | 南岳 | | 您好，南岳区税务局办税服务厅电话是…（填你的完整话术） |

几条规则（都是代码里的真实行为）：

- **列的顺序、位置随便**，靠列名识别，不靠第几列。
- 只有 `标题` 和 `内容` 都空的行会被当成空行丢掉；其余行都会生效。
- **没有 `标签` 的规则永远不会显示** —— 表里可以留着当草稿，但它不会出现在界面上。
  （例外：`是否常显` 勾了的行不需要标签，永远显示。）
- `必含关键词` / `剔除关键词` 这两列**可以整列不要**（脚本会自动当成「不约束 / 不剔除」），但只要你建了，名字就得写对。

### 内容里可以写魔法变量

在 `内容` 里写 `${Active_Cnt}`（正在对话人数），点按钮的**那一刻**会被替换成当前数字再填进输入框：

- 取值来自页面自身的状态（正在对话的人数），不会发任何网络请求；
- 每次点按钮都重新取值，所以数字总是最新的；
- 变量名写错（大小写不对、拼错）不会报错 —— 原样保留，方便你发现并改正。

### 隐私信息表格（可选的第二张表）

如果你还想放**办公地点 / 办公电话**这类随时要查的敏感信息，可以再建一张多维表格（列名跟主表完全一样），在设置里单独配置。`标题` + `内容` 起表；要让按钮真的显示出来，还需要 `标签`（命中才显示）或勾 `是否常显`（永远显示）：

1. 设置 →「飞书快捷回复」区块 → 找到 **隐私信息表格**（在规则表下方）；
2. 点它自己的 **从飞书选择表格** 直接选（v26.10.25-v2 起没有链接输入框，选完即保存）；
3. 条目会显示在快捷短语栏**上方**的独立一行（「隐私信息」标签）。

> ⚠️ **隐私表现在与主表走同一套匹配**（v26.10.26-v2，使用者定版）：`标签` + `必含关键词` + `剔除关键词` 一样生效。
> 想让它像速查表那样**一直显示**，就在表里把 `是否常显` 勾上 —— 勾上后无视一切匹配条件、对话为空也显示。
> 不勾「是否常显」又没有 `标签` 的隐私行**不会显示**（和主表同一个约定）。

不配这张表就什么都不显示，互不影响；「立即刷新规则」会同时刷新两张表。

**还有一个隐藏玩法：把「必含关键词」填成主管税务机关的全称**（如
`国家税务总局衡阳市南岳区税务局税源管理股`）—— 只要某个会话的主管税务机关正是这个局，
右侧栏那一行文本的右边就会直接冒出一个发送图标，点一下就把这条的 `内容` 填进输入框。
一个分局一条，坐席不用先看清是哪个分局再去栏里找。

> 判据是**文本相同**（只忽略空格/全半角/大小写），填短名（`南岳区税务局`）**不会**出图标 ——
> 因为同一个位置只能挂一条，用「包含」会挂错条。这条规则**不受** `标签` / `剔除关键词` /
> `是否常显` 影响，也不需要勾「是否常显」。

## 4. 第二步：指定要读哪张表（从飞书里直接选）

不需要找链接，让脚本把你有权访问的表列出来给你点。

1. 设置 →「飞书快捷回复（输出框上方的快捷短语，点击查看案例）」区块 → 点 **从飞书选择表格**；
2. 弹窗会自动列出这个飞书账号**有权访问的全部多维表格**（包括别人分享给你的、不在你自己云空间里的）；
3. 表多的话，在搜索框输标题关键词（**最多 30 字**）再点 **搜索**；留空就是列出全部；
4. 点中一条 → 立刻保存并刷新规则，不用再确认。

两点说明：

- 如果**看不到这个按钮**，或者显示「当前授权不含搜索权限」，说明你的授权是在这个功能上线之前做的
  —— 点一次 **重新授权**（只需一次确认）就会补上，不用重新注册应用；
- 列表里只会有**你有权限的表**。表在同事手里、又没把你加成协作者，这里就不会出现，让对方加你为「可阅读」即可。

链接形态的细节（脚本内部解析，供排查用）：

- `https://你的域名.feishu.cn/wiki/<节点token>?table=tbl…&view=vew…`（wiki 里的表，分享出来的通常是这种）
- `https://你的域名.feishu.cn/base/<appToken>?table=tbl…&view=vew…`（独立多维表格的直链）
- 链接里**不带** `table=` 参数 ⇒ 自动读这张表的**第一个**数据表。
- 链接里**不带** `view=` 参数 ⇒ 读整张表（推荐这样，免得只读到某个视图里看得见的记录）。
- 域名随意（含企业自建域名），脚本只认 `/wiki/…`、`/base/…`、`/bitable/…` 这段路径形态。

> ⚠️ 如果你在表格里给不同人配了不同视图，**别把 `view=` 留在链接里**——带上视图时只会读到该视图能看到的记录，改表后容易「明明改了却不生效」。

## 5. 第三步：授权并选好表（一次性，2 分钟）

1. 打开征纳互动平台，页面右上角标题栏点 **设置**。
2. 找到 **「飞书快捷回复（输出框上方的快捷短语，点击查看案例）」** 区块（就是本功能）。
3. 点 **授权飞书账号**，会走两个阶段，**每个阶段都要在浏览器里确认一次**：

| 阶段 | 界面提示 | 你要做的 | 有效期 |
|---|---|---|---|
| 第 1 步 / 共 2 步：注册应用 | 显示一个授权码和一个链接 | 点链接 → 在飞书页面确认「创建应用」 | 60 分钟 |
| 第 2 步 / 共 2 步：授权读取表格 | 新的授权码 + 链接 | 点链接 → **把权限全部勾选** → 确认 | **10 分钟** |

5. 面板出现绿色的 **已授权**、`规则 N 条` 就成功了（脚本会自动拉一次规则）。

> 💡 授权和选表**顺序可以互换**：老用户早就授权过了，直接点「从飞书选择表格」；
> 新用户先授权再选表，都能到同一个结果。

### 两个最容易踩的坑

**① 两步必须用同一个飞书账号。** 第 1 步注册出来的应用是「个人应用」，**只对创建它的那个账号可用**。如果第 1 步用 A 账号确认、第 2 步换成 B 账号登录，会提示「你没有「XX的智能助手」的使用权限」，怎么试都过不去。

补救：点面板上的 **作废并重新注册**（它会把本机凭证清掉），然后重新点「授权飞书账号」，这次**全程只用同一个账号**。

**② 第 2 步的授权页要「全部勾选」。** 少勾一个，后面读表会报 `app_scope_not_applied` 或「没有读取这张多维表格的权限」。看到这一步时别急着确认，先滚一遍把权限都打上勾。

### 授权之后会过期吗

会续期，正常用不会掉：访问凭证 2 小时、自动刷新；刷新用的凭证 7 天**滑动**续期（每次自动刷新重新计 7 天）。**只要不是连续一周没用过**，就一直有效。

真掉了（比如换电脑、清了浏览器数据），点 **重新授权** 只需要走上面第 2 步（一次确认），不用重新注册应用。

## 6. 平时怎么用

- 按钮出现在**整个输入区（含表情/截图那排工具栏）的上方**，一行横向滚动，多了就左右滑。
- **鼠标悬停**在按钮上，会显示这条规则的完整内容（可以先看再点）。
- 点一下 ⇒ 内容**整体替换**输入框，并提示「已填入：XXX」。检查一下就可以发。
- **切到别的会话会自动跟着换**（最多 3 秒），不需要手动刷新。
- 没命中任何规则时，界面上**不会多出任何东西**（不占高度、不挤压聊天区）。
- **常显按钮**（`是否常显` 勾了的）排在最前、永远在（哪怕对话是空的），后面用一条竖线和普通命中分开。
- 配了**隐私信息表格**的话，它单独占更上面一行：常显条目在最前，后面跟着匹配命中的条目，点一下同样直接填入。
- **主管税务机关右边的发送图标**：隐私表里某条的 `必含关键词` 正好等于这个会话的主管税务机关时，
  右侧栏那行文字的**末尾**会多一个纸飞机小图标（默认半透明，鼠标移上去变实）。点它 = 把那条的 `内容`
  填进输入框，效果等同于点快捷短语栏里对应的按钮 —— 差别是不用先在栏里找。换会话时图标会跟着变
  （那个会话的税务机关不在表里就没有图标）。

### 匹配到底怎么算（看懂了才好写标签）

取**当前会话最新的 10 条有文字的消息**（图片、文件、撤回提示不占名额），拼起来，再把右侧栏「会话人信息 → 企业信息 → **主管税务机关**」的全称追加到末尾（它不是消息，不占这 10 条的名额），然后按这个顺序判断：

1. 文本里**出现任意一个剔除关键词** ⇒ 该按钮直接不显示（一票否决，先于其它条件）；
2. 文本里**没有全部出现必含关键词** ⇒ 该按钮不显示（这一列为空则不约束）；
3. 文本里**包含任意一个标签** ⇒ 显示该按钮；
4. 没有标签的规则永远不显示。
5. 比较前双方都做归一化：**全角转半角、去掉所有空格、英文转小写** —— 所以「解非」「解 非」（中间带空格）算同一个词，`Email` 与 `email` 也是同一个词。

一句话记法：**剔除词一票否决 → 必含关键词全中 → 标签任一命中**。

只看最新 10 条是刻意的：半小时前聊过「注销」，现在聊「解非」，不该同时冒出两个按钮；
反过来 6 条又太窄，客户开头那句诉求常在窗口外（v26.10.26-v3 由 6 放宽到 10）。
把税务机关一起参与匹配，是为了「同一个问题、不同分局给不同答案」这类话术（比如南岳区 vs 其他区）。

## 7. 规则怎么写才准

### 标签

- **写对方可能怎么问，不是你怎么答**。客户打「非正常户怎么弄」，标签就该有「非正常户」「非正常」这类说法。
- **一个词 2~6 个字**，多写几个近义写法（「解非」「非正常户」「解除非正常」），命中率立刻上去。
- **别写太通用的词**：像「你好」「怎么办」「麻烦」「咨询」这种，几乎每通对话都有，一写就会满屏按钮。宁可窄一点，缺了再加。
- 标签写**短**、写**具体**；长句请放 `内容` 里。

### 必含关键词

它的作用是**缩小适用面**：标签写「电话」，全所的电话话术都会弹；加上必含「南岳」，就只在对话里
真的出现「南岳」时才给这条。

- 多值时**必须全部出现**（AND）才算通过；少一个就不显示。
- 留空 = 不约束（推荐留空，除非确实需要区分场景）。
- 可以和税务机关配合：把必含关键词写成 `南岳`，对话里出现「国家税务总局衡阳市南岳区税务局…」时也命中。

### 剔除关键词

它的作用是在「同一个词、不同场景」时闭嘴（一票否决，比必含/标签都优先）：

| 场景 | 标签 | 剔除关键词 | 效果 |
|---|---|---|---|
| 客户问「解非」，但已经办好了在问进度 | 解非 | 已解除、已经解除、办好了 | 只在真的还没解决时才出按钮 |
| 客户问「领票」，但要的是纸质票 | 领票 | 纸质、大厅 | 电子票话术不弹出来 |

⚠️ 剔除关键词是**子串**判断，只认字面：写「已申报」能拦住「已申报完成」「我已申报」，但**拦不住换了写法的**（「已经申报」「报过了」都不含「已申报」这三个连续字）。想拦稳一点，就把几种常见写法都加进剔除关键词。

### 标题

4~6 个字最好认，别把整句话塞进标题（按钮会被撑得很长，一行放不下几个）。

## 8. 改了表，多久生效

| 你做的事 | 怎么让它生效 |
|---|---|
| 改内容 / 加行 / 改标签 | 到设置里点一次 **立即刷新规则**，**3 秒内**按钮条就用上新规则 |
| 懒得每次点 | 规则缓存 5 分钟过期，过期后**下次打开 / 刷新页面**会自动重新拉一次 |
| 换了一张表 | 到设置里再点一次 **从飞书选择表格**，选中新表即自动保存并刷新 |

> ⚠️ 别指望「改完表干等着，界面自己就变」：按钮条只在内存里**还没有规则**时才会主动回源，
> 一旦加载过规则就一直用内存里那份。要立刻看到改动，就点「立即刷新规则」。

「立即刷新规则」失败不会把已有规则清空 —— 会用磁盘上的旧规则继续显示，60 秒后自动再试。所以偶尔看到「刷新失败」的提示，不用紧张，功能还在。

## 9. 常见问题

| 现象 | 怎么办 |
|---|---|
| 输入区上方一直没有按钮 | 先看设置面板：① 是否「已授权」；② `规则 N 条` 是不是 0（是 0 就点「立即刷新规则」）；③ 最近 10 条对话里是否真的出现了标签词，且没有踩到剔除关键词、必含关键词是否全部出现。三者都正常仍不出，说明这段对话就是没命中 —— 不是坏了。 |
| 面板报「没有读取这张多维表格的权限」 | 按顺序查：① 表是不是当前授权账号的（别人的表要让他把你加成「可阅读」协作者）；② 重新授权时 scope 是否**全部勾选**；③ 是不是选错了表 —— 点「从飞书选择表格」重新选一次。 |
| 授权页提示「你没有「XX的智能助手」的使用权限」 | 登录的账号不是第 1 步注册应用时的那个。切回原账号，或点 **作废并重新注册** 重来。 |
| 报 `access_denied：restricted by your organization's security policy` | 账号类型不支持给应用授予云文档权限 —— **豆包等第三方登录的账号都不行**（这不是公司策略）。换成有企业身份的飞书账号。 |
| 报 `app_scope_not_applied` | 授权时权限没勾全，点「重新授权」重走一遍，全部勾选。 |
| 报「搜索请求被飞书拒绝（99992402 参数不合法）」 | 飞书侧的泛化参数错误（旧版本因接口枚举大小写问题曾必现，**升级脚本**即可修复；仍出现就重试，或点「重新授权」换新 token）。 |
| 常显按钮（勾了「是否常显」）没显示 | ① 复选框要真的勾上；② 用文本列的话只认 `true` / `是` / `1` / `√`；③ 点一次「立即刷新规则」（≤3 秒生效）。 |
| 隐私信息栏一直不出现 | 两种情况：① 还没配隐私信息表格（可选，不配就不显示）；② 配了但那些行既没勾 `是否常显`、也没有 `标签` —— v26.10.26-v2 起隐私表参与匹配，速查项请勾「是否常显」。 |
| `${Active_Cnt}` 没变成数字 | 检查拼写与大小写（必须是 `${Active_Cnt}`）；写错的变量会原样保留在输入框里。页面状态取不到人数时会填 0。 |
| 点了按钮只提示「该规则没有填写「内容」列」 | 表里那一行的 `内容` 是空的。按钮靠 `标签` 就能显示，但没内容可填。 |
| 按钮出现了，点了没反应 / 提示「输入框未就绪」 | 页面还没进到会话（输入框没初始化）。进到具体对话里再点。 |
| 改了表、点了刷新，按钮变了但填进去的还是旧内容 | 基本是链接里带了 `view=`，你改的是别的视图里的记录。把链接里的 `view=…` 参数去掉，或确认改的是该视图内那条记录。 |
| 剔除关键词不生效 | 剔除关键词是子串匹配，检查是不是写成了更长的、对话里没出现过的句子（「已经申报」拦不住「已申报」这类换写法的）。 |
| 必含关键词填了但按钮不出来 | 必含关键词要**全部**出现才算过（多值 AND）；少一个、或写成别的说法都不行。不需要区分场景时把这一列清空即可。 |
| 按钮上显示的是内容前 12 字，不是标题 | 表里没有叫「标题」的列，或列名多了后缀（如「标题（必填）」）。列名必须一字不差；改好后点「立即刷新规则」。 |
| 选表 / 刷新时报「规则表链接无法识别」 | 选中的表链接形态不对：必须能看出 `/wiki/<token>` 或 `/base/<token>`。确认选的是多维表格本身，不是包裹它的文档页面。 |
| 看不到 **从飞书选择表格** 按钮，或提示「当前授权不含搜索权限」 | 这份授权是在「选表」功能上线之前做的，token 里没有 `search:docs:read`。点 **重新授权**（只需一次确认，不用重新注册应用）即可补上。 |
| 「从飞书选择表格」里找不到我的表 | ① 列表只显示**你有权限**的表 —— 别人分享的表要让对方把你加成「可阅读」协作者；② 有关键词时把搜索框清空再点搜索（留空 = 列出全部）；③ 确认它确实是**多维表格**，弹窗只列这一种类型。 |
| 换电脑 / 清了浏览器数据后失效 | 凭证存在本机，换机器要重新授权（走第 5 节第 2 步即可，一次确认）。 |

更多环境类问题（脚本没加载、面板不出现等）见 [troubleshooting.md](troubleshooting.md)。

## 10. 隐私：对话内容去哪了

- 对话文本（以及右侧栏的「主管税务机关」全称）**只在你的浏览器内存里**做字面匹配，**不发送到任何地方**；
- 唯一的网络请求是「读你那规则表」，只带授权凭证、**不带对话内容**；
- 运行日志只记「来源 + 命中了哪几条标题」，**不记对话正文**；
- 授权凭证存在脚本管理器（Tampermonkey / ScriptCat）的本地存储里，按脚本隔离，网页自身读不到；
- 它能读到的范围仅限**你这个账号本来就有权看**的多维表格 —— 换个人拿同样的凭证也读不到别人的表。

## 11. 别跟「常用语」搞混

功能列表里有两个看起来像的东西，是两套完全不同的机制：

| | **快捷短语**（本篇） | **常用语** |
|---|---|---|
| 话术从哪来 | 你自己的飞书多维表格 | 页面右侧栏的「常用话术」 |
| 怎么出现 | 按对话内容自动匹配，输入区上方浮出 | 打开弹窗，双 tab + 搜索，点卡片 |
| 更新方式 | 改表即可（可点「立即刷新规则」） | 脚本自动抓取本页右侧栏 |
| 详细文档 | 本篇 | [phrases.md](phrases.md) |

脚本界面里统一叫「**快捷短语**」，见到「常用语」指的是右侧栏那一套。
