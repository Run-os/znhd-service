# 图片嗅探

点标题栏「图片嗅探」图标，扫描当前网页上的图片（`<img>` / 懒加载属性 / CSS 背景图；内联 SVG 也采集但默认被后缀规则排除），支持放大预览、单张下载、批量下载与 A4 打印。

## 会话分组

在征纳互动工作台上，图片**默认按会话（纳税人）分组**：读取页面 Vuex 里的「当前会话 + 消息列表」，按**文件名**把每张图归到所属会话 —— 当前会话置顶，认不出归属的进「未归属会话」，组头显示「会话名（N 张）」并可一键全选本组；普通网页无会话概念时自动退回平铺列表。

- 组内按**消息时间从新到旧**排列；取不到时间的图排在最后、文件名标红。
  ⚠️ 时间来自消息对象：`time`（数值）→ `systemTime` / `talkTime`（`2026-10-26 14:56:39` 文本，本地时区）
  → `timestamp`。**2026-10-26 真机实测站点把 `time` 字段整个去掉了**（11/11 条消息 `typeof time === 'undefined'`），
  只认 `time` 的旧实现会让**每张图都判成无时间**（全红 + 组内退化成按体积排），v26.10.26-v6 已修。
  持久索引 `scriptCat_SniffConvIndex` 里旧的 `time: null` 记录，要等那次会话再被打开、重新读到消息才会补上。
- 「文件名 → 会话」映射持久化在 `localStorage`（键 `scriptCat_SniffConvIndex`，只记映射不记图片地址，30 天过期、最多 2000 条），因此切走会话后重新扫描，历史图片仍留在原分组。
- 会话别名表（显示名 → 真实会话 ID）+ 回退键后置合并，保证同一会话不会被拆成同名两组；名字匹配不唯一时宁可放弃（拆组）也不误合。

已知限制：工作台一次只给出当前会话的消息，**别的会话的图**要么当时还在页面上、要么点开那个会话再扫一次；图片直链带签名会过期（403），重扫即恢复。

## 体积测量（零请求优先）

1. **资源表预收**（`snifferPerf`）：脚本启动即扩容 performance 资源缓冲并起 observer 持续抄录；
2. 扫描时先查预收数据（`decodedBodySize → encodedBodySize → transferSize`），同源图零请求拿到大小；
3. 查不到才发 HEAD / Range 请求；
4. **后台预测量**（`snifferPre`）：启动 5 秒后后台把页面上的图量一遍，之后每 60 秒补新图 —— 打开嗅探窗口时直接复用，无需当场等。只有「跨域且资源表拿不到字节数」的图会在没开窗时被请求，介意可在设置里关掉「先在后台预测量图片大小」。

## 过滤与下载

- 最小体积阈值（默认 20 KB）可在嗅探窗口内调整并记住；小于阈值的图不显示也不参与全选。
- 名字含 `znhd-sniff` / `user-woman` / `user-man` 或 `.svg` 结尾的图在扫描阶段即排除。
- **批量下载**走两段式流水线（并发预取 + 串行间隔触发），失败自动重试、永久错误不重试。
- **A4 打印**：预览底部打印机图标按 A4 纵向无页眉页脚打印当前原图（打印对话框里缩放需选 100%）。

## 相关配置

阈值与预测量开关存于 `localStorage`（键 `scriptCat_Allvalue` 的 `sniffMinKB` / `sniffPreMeasure`），设置弹窗可改。
